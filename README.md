# Palmitessa family archive

A private static website for the Palmitessa family history, drawn from `Palmitessa-family-history.md`.

This repository is **private**. Do not switch it to public unless you intend the family account and living-person names to be on the open web.

## Open it locally

```bash
python3 -m http.server 8765 --directory .
```

Then open http://127.0.0.1:8765

Map tiles and webfonts need a network connection. Hash routes work if you open `index.html` directly.

## What the site contains

- **Story** — seven chapters from Monopoli to Plymouth
- **Two sides** — Palmitessa line on the left, Rudd household on the right
- **Tree** — Minnesota line, Rudd household, Scranton and Maine clusters
- **Timeline, Places, The IV, Clusters, Learn, Research, People**
- **Privacy** — scope of the file and what the browser stores

Documented facts, family account, hypotheses, and gaps stay labeled as in the original brief. Living people besides Dom are named only where published obituaries already name them, or where the subject supplied the name for this archive.

Place photographs are atmospheric stand-ins, not family property.

## Later, if you want a private live URL

GitHub Pages on a private repo requires GitHub Pro. Netlify/Cloudflare can also host the folder behind a password. Do not enable a public Pages site while this repo is meant to stay family-only.

## Keys

- `/` search
- `Esc` close
- `←` `→` previous / next chapter
- `?` shortcuts
- Theme toggle in the header (saved in the browser only)
